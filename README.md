# MealOra 

MealOra is a full-stack grocery tracking application built to learn modern web development.

## Features

- Add groceries
- Edit groceries
- Delete groceries
- Track expiration dates
- PostgreSQL database
- REST API built with FastAPI
- React frontend

## Tech Stack

- React
- FastAPI
- PostgreSQL
- Python
- JavaScript
- CSS

## Running Locally

Backend:

python -m uvicorn main:app --reload

Frontend:

cd frontend
npm install
npm run dev
